Three ways to start

One studio. Your source.

Choose a starting point in the editor. Each path feeds into a clear workflow instead of pretending every input automatically creates a finished movie.

✧
01 / PROMPT

Text to 3D cartoon

Describe the story, characters, mood, duration, output ratio and narration language. A compatible AI model is required to generate animated footage.

▶
02 / VIDEO LINK

Reference to new story

Use a supported video URL or authorized captions as a reference, then create a new script and original cartoon direction. YouTube watch links are not supported by every model.

▧
03 / UPLOAD

Your clip to cartoon plan

Upload a video to the configured backend or process it locally. Scene extraction and editing can run locally; AI transformation depends on model capability.

Production flow

From idea to final cut.

Keep the workflow modular, so the website can use free local editing alongside online AI providers without putting API keys in the browser.

1. SourcePrompt, supported link, or a video file you have permission to use.
2. PlanScript, character descriptions, scene prompts and narration plan.
3. Generate / editCompatible AI model for generated footage; local tools for trim, subtitles and audio.
4. ExportPrepare landscape YouTube, vertical Shorts, or square output.
Made for practical use

Creative control stays yours.

Use local tools where possible and connect a provider only when its capabilities, quota and licensing fit the project.
